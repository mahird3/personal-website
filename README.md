# Mahir Dursunoglu — Personal Website

Portfolio site inspired by [hudovich.com](https://hudovich.com/), built with Next.js and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

Edit content in `src/data/site.ts` and replace `public/profile.jpg` with your photo.
